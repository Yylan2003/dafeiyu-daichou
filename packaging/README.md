# 安装包维护

从 NSIS 官网安装或解压 Unicode NSIS，然后运行 `build-installer.ps1 -MakeNsis <makensis.exe完整路径>`。

脚本创建新的临时暂存目录，仅编译正式程序并收集运行素材；卸载文件清单自动从本次暂存内容生成。卸载仅删除清单中的文件，不递归删除整个安装目录，也不删除用户存档。

自动验证可以向安装程序传 `/S /VERIFY /D=<测试安装目录完整路径>`（`/D` 必须最后，目录不加引号）。`/VERIFY` 仅跳过快捷方式和注册表写入，不改变应用功能。测试目录带有 `.verify-install` 标记，卸载时据此跳过外部入口清理。真实用户安装不需要这些参数。

本项目不包含数字签名证书。需要签名发布时，使用自己的证书在构建后签署安装程序和应用程序。
